# 10daysjam

『くち、届く？』の試作プロジェクトです。

## ゲーム概要

呪いで体を動かせなくなった2人が、伸びる口だけを使ってステージを攻略する2Dパズルゲームです。2人の口先が接続するとキスが成立し、呪いが解けてステージクリアになります。

現在のバージョンでは、素材を使わず矩形と円だけでタイトル画面と3つのステージを表現しています。

## 操作方法

| キー | 操作 |
| --- | --- |
| WASD | プレイヤーAの口を1マス伸ばす |
| Z | プレイヤーAの口を1マス戻す |
| 矢印 | プレイヤーBの口を1マス伸ばす |
| Backspace | プレイヤーBの口を1マス戻す |
| R | ステージをリセットする |
| Esc | ゲームを終了する |

タイトル画面ではW/Sまたは上下キーで項目を選び、EnterまたはSpaceで決定します。ステージ選択ではA/Dまたは左右キーでステージを選択し、Backspaceでタイトルに戻れます。

## 実装済み

- 固定された2人のキャラクター
- グリッドに沿って曲げられる口
- 壁との当たり判定
- 自分・相手の口との重なり判定
- 2人のキャラクターを別々のキーで同時操作
- 口先の接続によるクリア判定
- リセットと再挑戦
- 操作説明付きタイトルメニュー
- 3ステージの選択画面
- メニューからのゲーム終了
