# 10daysjam

『くち、届く？』の試作プロジェクトです。

## ゲーム概要

呪いで体を動かせなくなった2人が、伸びる口だけを使ってステージを攻略する2Dパズルゲームです。2人の口先が接続するとキスが成立し、呪いが解けてステージクリアになります。

現在のバージョンでは、キャラクター・口先・箱・スイッチ・ハート・壁・床・ドア・クリア画面に画像素材を使用しています。

## 操作方法

タイトル画面はTitleScreen.png、クリア画面はClearScreen.pngを使用します。
音声はsound内のMP3をPCM WAVに変換して読み込みます（元のMP3も保持）。
bgmはループ再生、moveは口の伸縮成功時、selectはメニュー選択・画面切替時、
kissはクリア成立時に一度だけ再生します。

| キー | 操作 |
| --- | --- |
| WASD | プレイヤーAの口を1マス伸ばす |
| 矢印 | プレイヤーBの口を1マス伸ばす |
| 口が来た方向へ入力 | 口を1マス戻す |
| 箱へ向かって伸ばす | 箱を通路に沿って1マス押す |
| R | ステージをリセットする |
| Esc | プレイ中はタイトルへ戻り、タイトルではゲームを終了する |

タイトル画面ではSpaceで現在選ばれているステージを開始します。W/Sまたは上下キーで「ステージ選択」と「終了」を選び、Enterで決定します。ステージ選択ではA/Dまたは左右キーで解放済みのステージを選択し、Escでタイトルに戻れます。

最初はチュートリアルだけが解放されています。ステージをクリアすると次のステージが解放され、クリア画面でSpaceまたはEnterを押すと選択画面へ戻らず次のステージを開始します。最終ステージのクリア後はタイトルへ戻ります。

行動回数はステージごとに異なります。箱を押す操作も1回として数え、口を1マス戻すと使用回数も1回戻ります。
開いているドアを通過中にスイッチを離すと、閉じたドアに口が挟まれて操作不能になります。Rキーでやり直せます。

| ステージ | 青の上限 | 赤の上限 |
| --- | ---: | ---: |
| 01（チュートリアル） | 5 | 5 |
| 02 | 7 | 11 |
| 03 | 8 | 9 |
| 04 | 12 | 9 |
| 05 | 13 | 14 |
| 06 | 10 | 10 |
| 07 | 11 | 14 |

## 実装済み

- 固定された2人のキャラクター
- キャラクター・口先・箱・スイッチ・ハート・壁・床・ドアの画像表示
- キス成立時にキャラクターが灰色からカラーへ変化
- グリッドに沿って曲げられる口
- 壁との当たり判定
- 箱の押し出しと移動先の当たり判定
- 箱または口先で押せて、押下中は緑色に変わる床スイッチ
- スイッチと連動して開閉するドア
- 閉じたドアに挟まれた口の操作停止
- 第1ステージの直線型チュートリアル
- 第4ステージの2組の箱・スイッチ・ドア
- 第5ステージの2個の箱・スイッチ・ドア
- 第6ステージの交差対応する2組のスイッチ・ドア
- 第7ステージの番号対応する2組のスイッチ・ドア
- 自分・相手の口との重なり判定
- 2人のキャラクターを別々のキーで同時操作
- ステージごとに異なる行動回数制限
- 口先の接続によるクリア判定
- 専用画像を使用したクリア画面
- リセットと再挑戦
- 操作説明付きタイトルメニュー
- クリアによる次ステージの解放
- 解放済みステージだけを選べる7ステージの選択画面
- クリア画面から次ステージへの連続進行
- メニューからのゲーム終了
